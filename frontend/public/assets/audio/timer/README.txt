# HƯỚNG DẪN ĐẶT FILE ÂM THANH CHO CHẾ ĐỘ HẸN GIỜ (FOCUS TIMER & POMODORO)

Bạn hãy sao chép các file âm thanh (`.mp3` hoặc `.wav`) vào thư mục này:
`frontend/public/assets/audio/timer/`

---

## 🔔 1. Âm thanh chuông báo hoàn thành phiên (Completion Chimes):
- `bell_zen.mp3` : Chuông thiền / chuông bát Tây Tạng kết thúc phiên tập trung (mặc định)
- `bell_chime.mp3` : Tiếng chuông gió / chuông ngân nhẹ nhàng
- `bell_break.mp3` : Tiếng chuông báo hết giờ nghỉ giải lao, quay lại học

---

## 🎧 2. Âm thanh nền White Noise tăng cường tập trung (Ambient Loops - lặp mượt mà):
- `ambient_rain.mp3` : Tiếng mưa rơi rào nhẹ êm đềm
- `ambient_waves.mp3` : Tiếng sóng biển rì rào vỗ bờ
- `ambient_wind.mp3` : Tiếng gió đồi hoa thổi nhẹ
- `ambient_stream.mp3` : Tiếng suối róc rách trong rừng
- `ambient_fire.mp3` : Tiếng lửa trại / củi tí tách ấm áp

---

## 💡 Lưu ý:
- Nếu bạn chưa bỏ file vào, hệ thống vẫn có sẵn bộ tạo âm thanh tổng hợp tự động (Web Audio API) dự phòng để không bao giờ bị lỗi.
- Khi có file `.mp3` tại các đường dẫn trên, hệ thống sẽ tự động phát trực tiếp file âm thanh chất lượng cao của bạn!
